# Font Awesome motorcycle icon

The motorcycle silhouette in Crestmap's motorcycle crash marker is from
Font Awesome Free 7.3.1 by Fonticons, Inc.

- Source: https://github.com/FortAwesome/Font-Awesome/blob/7.x/svgs/solid/motorcycle.svg
- Icon license: Creative Commons Attribution 4.0 International
  (https://creativecommons.org/licenses/by/4.0/)
- Changes: the SVG path is scaled and translated into Crestmap's map marker and
  combined with the alert badge from Material Symbols Sharp's `car_crash` icon.

The Material Symbols Sharp license is at `licenses/material-symbols/LICENSE`.
